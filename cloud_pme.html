Cloud PME

Plateforme de gestion interne d'entreprise

Gestion des fichiers par département

Organisation automatique des fichiers selon les départements (RH, IT, Comptabilité, etc.).

Téléversement, suppression et partage sécurisé.

Permissions d'accès selon le rôle de l'utilisateur.

Messagerie interne

Échange de messages entre employés et employeurs.

Notifications internes en temps réel (via polling ou WebSocket futur).

Messages envoyés par les utilisateurs sont stockés dans la base de données avec historique complète.

Gestion Administrative & Gestion des demandes internes

Interface complète pour administrer l'entreprise

Gestion des utilisateurs, rôles, départements et permissions

Tableaux de bord pour suivre l'activité et les statistiques

Gestion des demandes internes (demande de congés, de formation, etc.)

Authentification

Système sécurisé de comptes utilisateurs personnalisés

Cloud PME est une application web interne développée avec Django permettant aux entreprises de gérer efficacement leurs fichiers, demandes et communications internes entre employés et employeurs.

Technologies utilisées

Python Django Spring Boot React HTML5 CSS3 MySQL
